some und any — einfach erklärt

some und any stehen vor unbestimmten Mengen. some in der bejahten Aussage, any in Verneinung und Frage — mit einer wichtigen Ausnahme bei Angeboten und Bitten.

Von ganz vorn

Ein Satz nach dem anderen, ohne Vorwissen.

some und any stehen vor Mengen, die man nicht genau angibt.

Auf Deutsch übersetzt man sie oft gar nicht: There are some tools heißt einfach Da sind Werkzeuge.

In einer normalen bejahten Aussage steht some.

Beispiel: There are some tools in the box.

In einer Verneinung steht any.

Beispiel: There aren't any sockets in this room.

In einer Frage steht ebenfalls any.

Beispiel: Are there any apples in the kitchen?

Eine Ausnahme gibt es: Wenn du etwas anbietest oder um etwas bittest, steht some, obwohl es eine Frage ist.

Beispiel: Would you like some tea? Oder: Could I have some water, please?

Wozu man das braucht

  • Beide Wörter kommen in fast jedem Satz über Mengen vor. Wer sie verwechselt, klingt sofort nach Anfänger, obwohl der Rest stimmt.
  • Im Betrieb: „Have we got any spare fuses?“ ist die Frage. „We have got some in the van“ ist die Antwort. Genau dieses Paar brauchst du dauernd.

Schritt für Schritt

  1. Schau dir den Satz an: bejahte Aussage, Verneinung oder Frage?
  2. Bejahte Aussage: some. There are some tools in the box.
  3. Verneinung: any. There aren't any sockets in this room.
  4. Frage: any. Are there any apples in the kitchen?
  5. Ausnahme: Bei einem Angebot oder einer Bitte steht some, obwohl es eine Frage ist. Would you like some tea?
  6. Der Grund für die Ausnahme: Du rechnest mit einem Ja.
  7. Im Deutschen bleiben beide Wörter meist unübersetzt — lass dich davon nicht verwirren.

Ein durchgerechnetes Beispiel

Aufgabe: Setz ein: „We haven't got ___ milk, but would you like ___ tea?“

  1. haven't got ist eine Verneinung → any
  2. would you like ist ein Angebot → some

Ergebnis: We haven't got any milk, but would you like some tea?

Die häufigsten Fehler

some in der Verneinung benutzt„There aren't some tools“ ist falsch. Nach einer Verneinung steht any.
any in der bejahten Aussage benutzt„We have got any milk“ ist falsch. In der Aussage steht some.
Bei Angeboten any benutzt„Would you like any tea?“ klingt unfreundlich bis seltsam. Bei einem Angebot steht some.
not und no zusammen benutzt„We haven't got no money“ ist doppelt verneint. Entweder haven't got any oder have got no.
some und any vor Zahlen benutztVor einer genauen Zahl steht keines von beiden: „three tools“, nicht „some three tools“.

Die Zeilen vier und fünf sind die Ausnahme, die man sich merken muss — sonst klingt jedes Angebot schroff.

Das Wichtigste in Kürze

  • Bejahte Aussage: some.
  • Verneinung: any.
  • Echte Frage: any.
  • Angebot und Bitte: some.
  • Nie doppelt verneinen.
  • Vor genauen Zahlen steht keines von beiden.
